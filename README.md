For this application, you can load it into a web browser, i used the integrated browser in vscode.
Begin by entering how many chapters you have to study, then select how difficult you believe they are, then tell it
how often you'd like to take a five minute break. This could be every minute, 15 minutes, or whenever works best for you. Use the calculate button to get an estimate on how much time you should set aside for your total study session. The number displayed will take into account every five minute break you would like, and the amount of actual study time. Use the start timer button to begin an on screen timer to help you keep track of your total time elapsed. whenever you press the stop timer, the timer will freeze so you can record how long you spent studying. When you begin the timer again, it will reset the timer to zero to begin a new study session.
